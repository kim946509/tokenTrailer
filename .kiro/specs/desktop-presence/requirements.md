# 작업표시줄·미니 위젯 상세 요구사항

상태: 검토용 초안 · 2026-10-19. [결정 목록](../README.md)을 따른다. F-09~F-11, F-13을 담당한다. Windows 11 작업표시줄 수치 직접 표시는 승인된 필수 목표이며 구현 방식은 설계에서 결정한다.

## DP-01. 작업표시줄 직접 표시

사용자 스토리: 사용자는 다른 작업 중 클릭하지 않고 사용량을 확인하고 싶다.

- DP-01.1 WHILE 상주 표시가 활성화되어 있고 Windows 작업표시줄이 보이면, 시스템은 작업표시줄 영역에서 사용량 수치를 직접 읽을 수 있게 해야 한다. 트레이 아이콘이나 클릭 후 팝업만으로 이 기준을 충족했다고 판정하지 않아야 한다.
- DP-01.2 WHEN 수치를 표시하면, 시스템은 연결 순서의 상위 2개 AI를 각 한 줄에 표시하고 각 AI의 주요 한도 창 사용률을 나란히 표시해야 한다. 오늘 토큰 합계는 작업표시줄에서 제외한다. Claude는 5시간·주간을 구분하고 실제로 조회되지 않은 창은 수치를 만들지 않아야 한다(2026-10-20 사용자 승인).
- DP-01.3 WHEN 표시를 클릭하면, 시스템은 전체 연결의 모든 한도 창·정확한 사용률·초기화 시각·실패 상태를 스크롤 가능한 팝업으로 제공해야 한다. 연결이 둘보다 많거나 한도 창이 여럿이어도 전체 정보를 확인할 수 있어야 한다.
- DP-01.7 WHEN 공간이 부족하면, 시스템은 먼저 AI 이름을 축약하고 그래도 부족하면 DP-01.4의 실패 상태를 제공해야 한다. 숫자 잘림이나 다른 버튼과 겹침을 성공으로 처리하지 않아야 한다.
- DP-01.4 IF 공간 부족이나 표시 생성 실패가 발생하면, THEN 시스템은 실패 상태와 복구 진입점을 제공해야 한다. 접근용 트레이를 보조로 사용할 수 있지만 직접 표시 성공으로 간주하지 않아야 한다.
- DP-01.5 WHEN 작업표시줄이 자동 숨김에서 다시 나타나면, 시스템은 Windows의 숨김 동작을 방해하지 않으면서 표시를 복원해야 한다. 시스템 아이콘·시작 메뉴 등 기존 조작 영역을 가리지 않아야 한다.
- DP-01.6 WHEN 상세 창이 닫혀 있으면, 시스템은 상세 열기·갱신·위젯 표시/숨김·설정·명시적 종료에 접근할 방법을 제공해야 한다.

## DP-02. 미니 위젯

사용자 스토리: 사용자는 작은 독립 창에서 도구별 토큰과 계정 한도를 보고 싶다.

- DP-02.1 WHEN 위젯을 표시하면, 시스템은 토큰·한도 사용률·초기화 정보를 각 범위와 함께 제공하고 같은 조건의 상세 화면과 일치하는 값을 사용해야 한다. 화면 배치는 설계에서 정한다.
- DP-02.2 WHEN 사용자가 이동·숨김·표시·항상 위 설정을 변경하면, 시스템은 성공적으로 저장된 선택을 재시작 후 복원해야 한다.
- DP-02.3 IF 저장 위치의 모니터가 없어지거나 배율 변경으로 접근 불가능해지면, THEN 시스템은 현재 화면 안의 접근 가능한 위치로 위젯을 이동해야 한다.
- DP-02.4 IF 토큰 수집이나 한도 인증이 실패하면, THEN 시스템은 위젯을 유지하며 해당 데이터 상태를 표시해야 한다. 사용자의 표시 설정을 자동으로 꺼서 저장하지 않아야 한다.
- DP-02.5 WHEN 위젯에서 상세를 열면, 시스템은 해당 도구·기간 또는 계정 한도 범위를 보존해야 한다.

## DP-03. 시작·닫기·종료

사용자 스토리: 사용자는 로그인 후 앱이 원하는 방식으로 나타나고 종료할 때 확실히 종료되기를 원한다.

- DP-03.1 WHEN 시작 설정을 변경하면, 시스템은 로그인 시 자동 시작과 시작 시 상세 창 숨김을 독립적으로 저장·적용해야 한다.
- DP-03.2 WHEN 자동 시작을 켜거나 끄면, 시스템은 OS 등록 결과를 확인하고 실패 시 실제 상태를 표시해야 한다. 설정 스위치 변경만으로 성공 처리하지 않아야 한다.
- DP-03.3 WHEN 로그인으로 앱이 시작되면, 시스템은 저장된 직접 표시·위젯·상세 창 설정을 적용해야 한다. 초기 수집이나 네트워크 응답을 기다리느라 표시 생성이 지연되지 않아야 한다.
- DP-03.4 WHEN 상세 창을 닫으면, 시스템은 상주를 유지하고 최초 사용 시 계속 실행됨과 종료 방법을 알려야 한다(D-07 제안).
- DP-03.5 WHEN 사용자가 앱 종료를 선택하면, 시스템은 갱신·네트워크 재시도·위젯·직접 표시를 종료해야 한다. 자동 시작 등록은 사용자가 끄지 않는 한 유지해야 한다.
- DP-03.6 WHEN 실행 중인 앱을 다시 실행하면, 시스템은 기존 앱에 접근하게 하고 중복 표시나 중복 수집 인스턴스를 만들지 않아야 한다.

## DP-04. 표면 복구와 상태 일치

사용자 스토리: 사용자는 재로그인·셸 재시작 후 앱을 수동 실행하지 않아도 표시를 회복하고 싶다.

- DP-04.1 WHEN Explorer가 재시작되거나 로그인 시 셸이 늦게 준비되면, 시스템은 사용 가능한 셸을 기준으로 직접 표시를 복구해야 한다. 복구 목표 30초는 D-08 제안이다.
- DP-04.2 WHEN 절전에서 복귀하거나 모니터·배율이 바뀌면, 시스템은 접근 가능한 표시 위치를 복원하고 기존 잔여 표면을 중복으로 남기지 않아야 한다.
- DP-04.3 IF 데이터 갱신만 실패하면, THEN 시스템은 표면을 유지하고 오래된 값/실패를 표시해야 한다. 표면 생성 실패와 데이터 실패를 별도 상태로 관리해야 한다.
- DP-04.4 WHEN 여러 표면이 같은 범위·스냅샷을 표시하면, 시스템은 같은 값을 제공해야 한다. 상세 화면의 다른 기간을 표시 중이면 오늘 기준 상주 수치와 범위 차이를 명시해야 한다.

## DP-05. 설정 저장과 접근성

사용자 스토리: 사용자는 설정이 실제로 적용됐는지 알고 키보드로도 앱을 조작하고 싶다.

- DP-05.1 WHEN 출처·갱신·자동 시작·창 표시·위젯 설정을 변경하면, 시스템은 적용값과 저장 결과를 구별하고 저장 성공값을 재시작 후 유지해야 한다.
- DP-05.2 IF 저장에 실패하거나 설정 파일이 손상되면, THEN 시스템은 실패를 알리고 기존 정상 설정을 조용히 덮어쓰지 않아야 한다. 복구/재시도 선택을 제공해야 한다.
- DP-05.3 WHEN 키보드로 설정을 변경하면, 시스템은 마우스 조작과 동일하게 저장하고 필터·표시/숨김·상세·종료에 접근할 수 있게 해야 한다.
- DP-05.4 WHEN 오류·지표를 표시하면, 시스템은 색상 외 텍스트·단위를 제공하고 접근 가능한 이름과 포커스 이동을 제공해야 한다. 초기 한국어 UI를 제안한다.
- DP-05.5 WHEN 사용자가 한도 갱신 주기를 바꾸면, 시스템은 선택 주기와 저장 결과를 표시하고 AQ-03.4에 따라 다음 허용 갱신에 적용해야 한다. 서버 요청 제한으로 더 오래 기다릴 때는 그 상태를 표시해야 한다. AICap 참고 선택지·기본값과 나머지 설정은 [설정 검토안](settings-review.md)에 구분한다.
- DP-05.6 WHEN 사용자가 AI 순서를 드래그 또는 키보드 버튼으로 변경하고 저장하면, 시스템은 연결된 AI의 상대 순서를 작업표시줄·위젯·전체 한도 팝업에 적용하고 재시작 후 유지해야 한다. 연결하지 않은 AI는 표시 후보에서 제외한다.

## 수용 시나리오

실제 Windows 11에서 자동 시작 켬/끔 × 시작 창 숨김 켬/끔의 4조합, 수동 중복 실행, 창 닫기와 앱 종료를 각각 확인한다. Explorer 재시작·로그인 지연·절전 복귀, 단일/듀얼 모니터 연결 해제, 배율 100/150/200%, 작업표시줄 자동 숨김을 시험한다. 주 모니터 표시를 기본안으로 하며 여러 작업표시줄 동시 표시가 필수인지는 추가 검토한다.

검증 연결: V-02, V-04~V-06. 실제 표면이 보여야 통과하며 프로세스 실행·함수 호출 성공만으로 판정하지 않는다. 지원 Windows 빌드·배율·화면 해상도와 결과를 기록한다.

- DP-05.7 WHEN 한도 사용률을 표시하면, 시스템은 각 한도 숫자의 글씨를 60% 미만 초록(#76db9b), 60% 이상 90% 미만 주황(#ffb454), 90% 이상 빨강(#ff7078)으로 표시해야 한다. 작업표시줄·대시보드·위젯·팝업에 동일 기준을 적용하고 미확인 값은 중립색으로 유지한다. 판정은 반올림 전 수치 기준이다(2026-10-20 사용자 요청).

- DP-01.8 / DP-02.6 WHEN 작업표시줄 수치 또는 위젯 내용 영역을 오른쪽 클릭하면, 시스템은 전체 연결의 한도별 초기화 시각과 남은 시간을 포인터 근처의 화면 안에 표시해야 한다. 기존 왼쪽 클릭 동작은 유지하고, 시각 미확인 및 예정 시각 경과를 실제 초기화 완료와 구분해야 한다(2026-10-20 사용자 요청).

## 2026-10-20 UX 재검토 반영 (최신)
DP-01.8/DP-02.6의 우클릭 팝업 제안을 대체한다. WHEN 위젯 또는 작업표시줄 수치를 우클릭하면, 시스템은 동일 위치의 사용률 숫자를 초기화 남은 시간으로 바꾸고 재차 우클릭 시 복귀해야 한다. 작업표시줄 왼쪽 클릭의 전체 한도 팝업은 유지한다. 위젯은 연결된 AI의 작은 행·막대를 표시하며 미연결 항목은 설정 밖에 표시하지 않는다. 설정은 AI 연결/상주 표시/앱 시작 그룹으로 구분하고 고급 기록 경로는 접어 둔다. 순서 변경은 ↑↓ 및 드래그를 제공한다.

- DP-05.8 WHEN 사용자가 체크박스·주기·순서를 변경하면, 시스템은 별도 저장 버튼 없이 즉시 저장·적용하며 설정 화면에 머물러야 한다. 경로는 change(포커스 이동/Enter) 시 저장하고 저장 중/성공/실패와 재시도를 제공해야 한다. 연속 변경은 순서대로 저장한다.

## 미니멀 위젯과 배경 불투명도 (2026-10-20 사용자 요청)

- 위젯을 표시할 때 앱은 제목·도구모음·하단 안내 없이 연결된 AI의 작은 기호, 한도 이름, 막대, 사용률만 표시해야 한다. 기존 드래그 헤더 요구를 대체한다.
- 우클릭 또는 Shift+F10 시 같은 행에서 사용률과 초기화까지 남은 시간을 전환해야 한다. 아이콘 영역으로 이동하고 본문 더블클릭으로 상세 창을 열 수 있어야 한다.
- 배경 불투명도는 30~100%로 설정하며 조작 완료 시 즉시 저장·적용해야 한다. 글자·막대에는 불투명도를 적용하지 않아야 한다. 기존 설정에는 100% 기본값을 적용한다.
- 연결된 AI/한도 수 변경 시 높이를 자동 조절해야 하며, 미확인 값은 0%로 표시하지 않아야 한다.

## 작업표시줄 우클릭 메뉴 변경 (2026-10-20 승인)

작업표시줄 우클릭 시 사용률 숫자를 시간으로 치환하지 않고 바로 위의 작은 메뉴에 연결된 AI별 한도 이름·남은 시간·초기화 시각을 표시해야 한다. 화면 작업 영역 안으로 위치를 제한하고 바깥 클릭에 의한 포커스 이탈 또는 Esc로 닫아야 한다. 위젯의 기존 우클릭 전환은 유지한다. 이전 작업표시줄 inline 시간 전환 요구를 대체한다.

## 작업표시줄 정보창 최종 변경 (사용자 승인)

작업표시줄 도우미가 직접 여는 정보창 하나를 재사용한다. 기존 다크 배경·민트 AI 이름과 밝은 남은 시간만 표시하며, 절대 날짜·시각 및 메뉴 선택/호버 효과를 제거한다. 우클릭으로 열기/재우클릭으로 닫기, Esc와 창 바깥 클릭으로 닫기를 지원한다. 단순 포커스 이탈에 의존하지 않는다. 기존 Electron 별도 메뉴 창 및 기본 명령 메뉴 설계를 대체한다.

## 작업표시줄 클릭 동작 변경 (2026-10-21 사용자 승인)

왼쪽 한 번 클릭은 아무 동작도 하지 않는다. 왼쪽 더블클릭은 메인 앱을 열고 최소화 상태이면 복원한다. 우클릭은 기존 초기화 정보창을 토글한다. 네이티브 창 클래스 CS_DBLCLKS 및 WM_LBUTTONDBLCLK를 사용하며, 단일 클릭용 한도 팝업 호출은 제거한다.
