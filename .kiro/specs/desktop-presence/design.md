# 상주 표시 MVP 설계

2026-10-20 MVP 구현 승인 반영. [MVP 공통 설계](../../../docs/MVP_DESIGN.md)를 따른다.

Electron main이 대시보드·미니 위젯·트레이를 관리하고 모든 표면은 같은 Engine 스냅샷을 사용한다. 위젯 위치/항상 위/표시와 시작 시 창 숨김은 앱 설정으로, 자동 시작은 Electron login item API의 실제 결과를 확인해 저장한다. 창 닫기는 숨김이며 명시적 종료는 수집 타이머·네트워크 요청·보조 프로세스를 정리한다. 단일 인스턴스 잠금을 사용한다.

Windows 직접 표시는 `src/native/taskbar.ps1`이 `taskbar.cs`를 Windows PowerShell 5.1에서 로드한다. 주 작업표시줄의 DPI 문맥에서 layered child를 만들고 1.5초마다 셸·부모·공간을 재확인한다. UI Automation의 버튼/텍스트 등과 알려진 ReBar/알림 영역을 제외한 공간만 선택한다. 좌측 위젯/우측 시스템 영역은 별도로 예약한다. 확인 실패/공간 부족 시 창을 제거하고 상태를 반환한다. 다른 앱 창 크기나 Explorer 설정을 바꾸지 않는다.

보조 프로세스에는 한도 표시 문자열(전체/AI 이름 축약)·표시 여부만 UTF-8 파일로 전달한다. 인증이나 경로를 전달하지 않는다. `presence.mjs`가 연결 순서 상위 2개의 한도 문자열을 만들고 C#은 글자 폭을 측정해 전체 이름부터 빈 공간에 배치한다. 둘 다 불가능하면 숨김/실패 상태를 유지한다. 클릭은 표준 출력 이벤트로 주 화면 우측 아래에 전체 한도 팝업을 연다. 팝업은 기존 한도 카드와 IPC 검증을 재사용하며 포커스 상실/닫기 시 숨긴다. 부모 앱 종료 시 보조 프로세스도 종료한다. 작업표시줄 표시는 OS 공식 확장 계약이 아니므로 빌드별 실화면 검증이 필요하다.

2026-10-20 추가 승인: `connectionOrder`에 AI 순서를 저장하고 로컬 수집 또는 한도 조회가 켜진 항목을 연결로 취급한다. 기존 설정에 순서가 없으면 이전 `selectedProvider`를 우선해 이관한다. 신규 기본 순서는 Claude/Codex/Gemini다. 작업표시줄은 최대 두 AI·각 두 한도 창, 추가 창은 `+N`; 위젯/팝업은 전체 연결과 모든 창을 표시한다. 한 제공자당 하나의 연결만 지원하며 계정별 기록 귀속은 추가하지 않는다.

위젯 위치는 현재 모니터의 작업 영역 안으로 보정한다. 절전 복귀/디스플레이 변경 시 위치와 데이터 갱신을 재확인한다. 자동 숨김·실제 셸 재시작·재로그인·다중 모니터·배율 조합을 시험하기 전 전체 복구 보장으로 표현하지 않는다.

한도 글씨 색: UI는 quota-color.mjs를 공유한다. 작업표시줄에는 표시 순서에 맞춘 원본 사용률 배열을 전달하고 각 % 구간만 개별 색상으로 그린다. 이름·기간·구분자는 중립색을 유지한다.

오른쪽 클릭은 기존 전체 한도 팝업을 재사용한다. 위젯은 Electron context-menu, 작업표시줄은 WM_RBUTTONUP → helper rightClick 이벤트로 연결한다. 가까운 화면 작업 영역에 팝업을 배치하고 열 때 스냅샷을 다시 읽는다. reset-time.mjs가 현지 절대 시각·분 단위 올림 남은 시간·미확인·경과 상태를 제공한다.

최신 UX 설계: REA에서 확인한 AICap의 inline %/시간 전환을 참고한다. widget renderer는 contextmenu를 차단하고 local 표시 상태만 토글한다. taskbar helper는 WM_RBUTTONUP에서 ShowResetTimes를 토글하고 준비된 시간 문자열을 그린다. 별도 Electron 팝업의 포커스 상태에 의존하지 않는다. 근거/검증 한계는 docs/research/aicap/widget-ux-improvement.md 참조.

설정 즉시 저장: 폼 change 및 순서 이동에서 현재 설정 스냅샷을 순차 저장한다. 각 요청의 revision으로 최신 결과만 상태에 표시한다. 경로는 입력 완료 시 저장한다. 기존 main 저장 검증/자동 시작 등록 검증을 유지하며 출처 설정이 변하지 않은 표시 변경은 API 강제 조회를 반복하지 않는다.

## 미니멀 위젯 변경 (2026-10-20)

폭 250 DIP, 한도 행 20 DIP, AI 그룹 세로 여백 10 DIP와 구분선 1 DIP. 연결 2개·한도 각 2개는 104 DIP 높이. 이전 저장 폭은 새 고정 폭으로 대체하고 위치는 유지한다. 제목/도구 버튼은 제거하고 기호 열만 drag 영역으로 사용한다. 나머지 본문에서 우클릭/더블클릭, 키보드 Shift+F10을 제공한다.

widgetOpacity(0.3~1)는 Engine 설정 검증·저장 경로를 재사용한다. 기존 파일에서 필드가 없으면 1로 이관한다. Electron 투명 창 및 투명 document 위의 위젯 배경에만 RGBA alpha를 적용한다. Windows 창 전체 setOpacity는 사용하지 않는다. 설정 range change를 기존 자동 저장 큐에 연결한다. AICap의 CSS 배경 alpha 구조를 참고하되 Electron에서 배경 blur는 적용하지 않는다.

## 작업표시줄 초기화 시간 메뉴

네이티브 helper는 우클릭 이벤트만 보내며 Caption/CompactCaption의 % 표시를 유지한다. 메인 프로세스는 별도 프레임 없는 320 DIP 정보 창을 작업표시줄 도우미의 물리 좌표를 DIP로 변환한 위치 위에 연다. 대상 모니터 workArea에 좌표·높이를 제한한다. 내용이 화면보다 많으면 스크롤한다. blur와 Escape는 창을 숨긴다. 기존 스냅샷 IPC의 호출자 검증 대상에 메뉴 창을 명시적으로 포함한다. 연결 순서와 quota 활성 상태를 따르며 남은 시간은 기존 remainingTimeText를 재사용한다. 왼쪽 클릭의 전체 한도 팝업과 위젯 inline 전환은 유지한다.

## 도우미 내부 정보창으로 대체

네이티브 helper는 재사용하는 프레임 없는 WinForms 정보창을 직접 연다. ShowWithoutActivation/NOACTIVATE로 앱 창 사이의 포커스 전달을 피한다. 정보창이 열려 있는 동안에만 마우스/키보드 저수준 hook을 설치한다. 마우스 누름 시 정보창·작업표시줄 영역 밖이면 닫고 입력은 원래 대상에 전달한다. Esc는 닫고 소비한다. 좌클릭은 누름/뗌 쌍만 인정하며, 재우클릭은 정보창을 토글한다. 닫기·종료·작업표시줄 제거 시 hook을 해제한다. hook 설치 실패 시 닫힘이 불안정한 창을 열지 않고 오류 상태를 보고한다. 키 입력 내용이나 외부 창 내용을 저장하지 않는다.

열려 있는 동안 UIA 작업표시줄 배치 스캔을 건너뛰어 입력 hook의 메시지 처리를 지연시키지 않는다. 화면 영역에 크기/위치를 제한하고 내용이 많으면 스크롤한다. 가로 280 DIP, 정보 행은 24 DIP, AI 이름/남은 시간 두 열로 렌더링한다. 열 때 최신 스냅샷을 사용한다.

## 작업표시줄 클릭 동작 변경 (2026-10-21 사용자 승인)

왼쪽 한 번 클릭은 아무 동작도 하지 않는다. 왼쪽 더블클릭은 메인 앱을 열고 최소화 상태이면 복원한다. 우클릭은 기존 초기화 정보창을 토글한다. 네이티브 창 클래스 CS_DBLCLKS 및 WM_LBUTTONDBLCLK를 사용하며, 단일 클릭용 한도 팝업 호출은 제거한다.
