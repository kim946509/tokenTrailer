# 제공자별 로컬 토큰 수집 설계

상태: 사용자 검토용 제공자 수집 설계안 · 2026-10-19. [요구사항](requirements.md)의 제공자 수집 경로를 구체화한다. 전체 저장소·UI·이력 삭제 구현 설계는 별도이며, 아래 경로의 실제 Windows 버전별 지원 검증은 남아 있다.

## 계정 한도와 분리

시간·프로젝트·세션 분석은 로컬 사용 기록을 읽는다. 계정 요금제 한도는 [한도 수집 설계](../account-quota/design.md)의 API로 읽는다. 한도 %는 토큰 수로 변환하지 않고, 로컬 기록을 현재 로그인 계정에 자동 귀속하지 않는다.

| 도구 | 최초 수집 후보 | 처리와 이유 |
|---|---|---|
| Claude Code | 선택한 Claude 홈의 projects 아래 지원 JSONL | 메시지별 실측 usage·시각·프로젝트·세션 확보. 스트리밍 중복은 지원 버전별 메시지 식별자로 갱신 |
| Codex CLI | 선택된 CODEX_HOME의 sessions 및 archived_sessions | 실측 이벤트·누적값 구분, 누적 차분·동일 이벤트 재전송·archive 이동 중복 처리 |
| Codex 데스크톱 | 실제 Windows 버전에서 확인한 로컬 기록 출처 | CLI와 동일 출처가 확인되면 같은 파서 사용. 별도 저장소면 자료 확보 후 별도 형식 지원. 데스크톱이라는 이유로 CLI 자료만으로 검증 완료하지 않음 |
| Gemini CLI | 선택한 Gemini 홈의 tmp 프로젝트 chats 기록 | 버전별 JSON/JSONL usage 파싱. 캐시/입력과 thoughts/출력 포함 관계 확인 |
| Kimi CLI/Code, 후속 | wire usage 또는 usage.record 형식 후보 | 실측 필드가 있는 버전부터 지원. 제품·버전 간 포맷을 동일하다고 가정하지 않음 |
| Grok Build, 후속 | unified inference 기록 후보 | 실측 usage를 우선하며 문자 기반 context 추정은 합계 제외 |

위 후보는 [CodeBurn 분석](../../../docs/research/CODEBURN_ANALYSIS.md)과 고정 버전 소스에서 얻었다. 지원 버전과 경로를 실제 fixture로 확정한 뒤 지원 목록에 등록한다. Gemini 계정 한도 API가 미지원이어도 남아 있는 지원 로컬 기록은 읽을 수 있으나 이것이 Gemini 한도 조회 출시 조건을 충족하지는 않는다.

## 최소 처리 흐름

1. 사용자가 연결한 출처에서 지원 파일 목록을 얻고 최초에는 전체 지원 기록을 처리한다. 디렉터리 밖으로 향하는 연결/재분석 지점은 자동 추적하지 않고 범위를 확인한다.
2. 형식별로 사용 이벤트를 읽어 도구·출처·이벤트 식별 근거·시각·프로젝트·세션·모델·실측 토큰 구성으로 정규화한다. 세부 합계는 UC-03 계약을 적용한다.
3. 동일성 확인이 가능한 이벤트는 중복 삽입 대신 갱신한다. source identity와 논리 event identity를 구분해 파일 이동/복사로 총량이 늘지 않게 한다. 근거 없는 추정 병합은 하지 않는다.
4. JSONL은 완료된 행까지 처리하고 작성 중인 마지막 행은 보류한다. JSON 전체 교체형 기록은 안정된 스냅샷을 읽고 내용 변경 시 재평가한다. 누적 카운터 감소는 임의 음수 차분으로 처리하지 않는다.
5. 파일별 진행 위치/변경 정보를 기록한다. 30초 기본 재탐색·증분 처리 제안이며 전체 기록을 매번 재집계하지 않는다. 파일 축소·교체는 재평가하되 논리 이벤트 중복 방지를 유지한다.
6. 확보한 메타데이터와 수집 범위를 로컬에 보존한다. 원본 삭제는 앱 이력 삭제를 의미하지 않는다. 앱 삭제 후 재수입 방지는 UC-05 검토안에 따르며 식별정보·삭제 원자성의 상세 설계는 후속이다.

단일 공통 이벤트 모델과 도구별 파서만 두고 플러그인 서버·MCP·클라우드 동기화는 만들지 않는다. 파서 자체는 원본 파일 쓰기 권한이나 인증정보를 필요로 하지 않는다.

## 검증

UC-01~UC-04·UC-06에 연결해 도구/버전별 정상·일부 손상·증가·복사·누적·분기 fixture를 사용한다. 동일 자료 반복 수집 및 재시작 후 총량 불변, 캐시·추론 중복 없음, 경계 시각과 미귀속 보존을 검증한다. 원본을 수정하지 않았음을 확인한다. 사용자 실제 대화 원문을 fixture로 저장하지 않는다.

결정 필요: 지원 버전·출처, Codex 데스크톱 실제 기록 형식, 기본 합계 정의(D-04), 삭제·재수입 정책 세부(D-06). 본 문서 작성으로 해당 제안이 승인되거나 실제 데이터 접근이 허용된 것으로 해석하지 않는다.
