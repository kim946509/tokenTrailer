# 사용량 분석 MVP 설계

2026-10-20 MVP 구현 요청에 따라 작성. 공통 설계는 [MVP 설계](../../../docs/MVP_DESIGN.md).

`src/analysis.mjs`가 모든 표면의 기간 합계를 계산한다. 오늘·주·월은 PC 현지 시간, 주 시작은 월요일이다. 시간 구간은 실제 epoch 1시간 간격으로 만들어 DST 반복 시간을 보존하고 일 구간은 현지 날짜를 증가시킨다. 범위는 시작 포함·끝 제외다.

기간·도구 → 시간 구간 → 프로젝트 → 세션으로 필터를 좁힌다. 구간을 선택해도 전체 기간 그래프는 유지한다. 프로젝트와 세션 목록은 동일 필터를 쓰며 목록 합계가 요약과 같아야 한다. 세션 상세는 확보된 전체 이력과 개별 이벤트를 표시한다. 제목은 세션 식별자를 쓰며 대화 원문을 분석하지 않는다.

그래프는 HTML 버튼 막대와 동등한 정확한 수치 표를 제공한다. 시각 미확인 기록은 기간 합계에 넣지 않고 별도로 수량·토큰을 설명한다. 계정 한도 카드는 토큰 기간과 독립이며 서로 환산하지 않는다. 불완전한 자료를 확정 계정 총량이라고 표현하지 않는다.

검증: `tests/collection.test.mjs` 경계 시각·프로젝트 합계와 Electron `src/smoke.mjs` 그래프 선택 시험.

2026-10-20 추가 승인: 연결 목록은 Engine의 설정에서 파생하고 `connected` 필터의 허용 AI를 백엔드에서 정한다. renderer가 보낸 임의 허용 목록은 사용하지 않는다. 분석은 기존 프로젝트 `providers` 합계를 재사용하고 선택 기간/구간의 `providerTotals`를 추가한다. 프로젝트 선택은 세션 목록을 좁히며 상단 요약은 기간/구간/AI 범위다. 연결 해제된 기록은 전체 기록과 별도 보존 기록 항목으로 계속 조회한다. 한 제공자 내 복수 계정의 구분은 하지 않는다.

검증 추가: `tests/presence-analysis.test.mjs`의 AI/기간/프로젝트/구간 교차 조건, `src/smoke.mjs`의 실제 필터 선택과 프로젝트·세션 수치 확인.

token-format.mjs는 en-US Intl compact 형식으로 표시 문자열만 만든다. 원값은 기존 집계로 유지하고 title 및 그래프 접근성 이름/정확한 구간 표에 제공한다. 미확인은 —로 유지한다.
