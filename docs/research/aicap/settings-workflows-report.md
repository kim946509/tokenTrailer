# AICap 설정·부가 기능 정적 분석

대상: AICap 0.7.5 복원 자산 `frontend/assets/index-BbaXIiVU.js`. 모든 위치는 JavaScript 문자열의 UTF-16 [start,end) 좌표다. 실제 계정·설정·백업 파일을 열거나 IPC/API를 실행하지 않았다. 아래는 배포된 프런트엔드 코드에서 확인한 호출·분기이며 네이티브 구현 보장은 별도로 표시한다.

## 자료 기반으로 구분할 중요한 지점

1. 백업 한국어 안내([85009 부근])는 설정과 계정 인증정보를 포함하고 오래된 인증정보는 재인증이 필요할 수 있다고 설명한다. 복원 안내([85593 부근])는 현재 설정/인증정보 교체 후 재시작이라고 말한다. 코드에서 비밀번호를 backend로 전달하고 복원후 재시작하는 흐름은 확인했지만, 안내문만으로 강한 암호화·복원안전성을 검증한 것은 아니다.
2. Drive 복원후 삭제 기본값은 pa의 `useState(!0)`와 복원창 열 때 `te(!0)`, 복원성공 후 `if(ee) deleteGoogleDriveBackup`로 확인된다. 자동삭제를 실행한 적 없다.
3. fo의 낙관적 저장은 실패시 화면/디스크 상태가 달라질 가능성이 있다. 실제 저장실패 재현은 없으므로 현재 자동시작 문제의 원인으로 확정하지 않는다.
4. 위젯 투명도 Na 컴포넌트[217743,218327)는 onChange로 임시값 변경, onMouseUp으로 저장한다. 키보드 조작만으로 저장되느냐는 별도 검증 항목이며 실행 검증하지 않았다.
5. 스케줄러는 사용자 작업을 관찰만 하는 기능이 아니라 자동 요청을 보낼 수 있다는 제품설명이다. TokenTrailer 요구사항에서 관측·알림 기능과 별도 검토해야 한다.
6. 설정화면 메뉴상 존재하는 것과 실행 코드가 들어 있으나 메뉴에서 제거된 것을 구분했다. openSettingsFile/openAppConfigFile/openLogFile은 래퍼 외 참조0개다.

## 검증 파일

- `settings-extract.cjs`: 설치된 REA의 Babel parser로 FunctionDeclaration 추출, 원본파일수정 없음.
- `settings-functions.json`: 원본코드 구간/함수명 전체 목록. 소스는 배포자산만, 실제 사용자 credential을 포함하지 않는다.
- 네이티브 분석은 부모 에이전트가 별도로 수행한다. 이 보고서는 사용자기능과 프런트엔드 실행 경로에 대한 근거다.
