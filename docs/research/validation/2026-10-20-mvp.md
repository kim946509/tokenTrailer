# 로컬 MVP 구현·검증 결과

2026-10-20. 사용자 승인 범위: 테스트하며 MVP까지 구현. 커밋·배포·비교 앱 수정은 수행하지 않았다.

## 산출물

- 앱 소스: `src/`, 합성 테스트: `tests/`, 패키지/검증 스크립트: `scripts/`.
- 실행 패키지: `dist/TokenTrailer/TokenTrailer.exe`. 전체 폴더가 필요하다.
- Electron 44.9.0을 고정했다. 공식 배포 ZIP의 SHA256은 npm 패키지 checksums.json과 일치했다: `88e08039d0ef359bab9f674e8051fa103bd8628ea7c5a5e1daaa610a8a0c6931`.
- 폴더형 실행 파일 SHA256: `c99a56d653220a8bf209b0b9ae2424ec1f1580946d1bf3395a968eb211a4f1b5`. 이 해시는 Electron 런타임 실행 파일 해시이며 JS 앱 전체 무결성 서명을 의미하지 않는다.
- Electron의 GPU 캡처가 현재 환경에서 UnknownVizError를 반환해 소프트웨어 렌더링으로 전환했다. 이후 기본 실행과 패키지 시험이 통과했다.
- 첫 실행 가시성 검사 실패 후 loadFile 전에 표시 이벤트를 등록하고, 표시 완료를 기다리는 `initialWindowVisible` 검사를 추가했다. 테스트 실행기의 숨김 시작 옵션도 분리하여 일반 실행에서 소스와 패키지를 재검증했다. 렌더링/캡처 성공만으로 화면 노출을 판정하지 않는다.

## 아직 통과하지 않은 출시 조건

- Gemini 실계정의 실제 한도 및 기록 생성 대조. 구현·합성 테스트는 완료했지만 필수 3개 실조회 출시 조건은 미충족이다.
- 실제 Explorer 재시작·로그인/로그아웃·절전 복귀·자동 시작 4조합·단일 인스턴스 중복 실행의 실기기 행렬.
- 150/200% DPI, 다중 모니터, 자동 숨김, 다른 Windows 빌드의 직접 표시. Win32 호출 성공만으로 이러한 환경까지 표시 성공이라고 판단하지 않는다.
- 부모 없는 Codex 분기와 Gemini `$set` 업데이트 확장, 128MiB 초과 파일, 대규모 이력 성능 수용 기준.
- 인증 파일 변화 감지는 계정 식별을 증명하지 않는다. 화면에서 계정 미확인 상태를 유지하며 PC 이력을 현재 계정에 자동 귀속하지 않는다.
- 설치 관리자·코드 서명·자동 업데이트는 MVP 범위 밖이다. Electron 기반이므로 Tauri보다 실행 패키지가 크다.

결론: 실행 가능한 로컬 MVP와 패키지 검증을 완료했다. 전체 요구사항의 출시 수용 행렬을 모두 통과한 제품으로 표현하지 않는다.

## 정보창 여닫기 및 UX 최종 수정

이전 Electron 정보창과 기본 ContextMenuStrip 구현은 최종안이 아니다. 사용자 승인에 따라 도우미 내부의 재사용 WinForms 정보창과 열려 있는 동안만 설치하는 outside-click/Esc hook으로 대체했다. 다크 배경/민트 AI 이름/밝은 남은 시간을 유지하고 날짜·메뉴 호버를 제거했다.

단위 22개 통과. 소스 smoke에서 5회 열기, 동일 HWND 재사용, 재우클릭 닫기, Esc 메시지 닫기 통과. TT_OS_DISMISS_TEST=1에서는 실제 Esc 입력과 정보창 바깥의 항상 위 위젯을 클릭하여 닫기 통과. 본문 스크린샷 taskbar-reset-info.png 검토. 앱 main 창은 다른 창에 가려져 주입을 거부했으므로 소유권·가림 검사를 완화하지 않고 별도 위젯을 안전한 외부 클릭 대상으로 사용했다.

패키징의 전체 OS 우클릭 주입은 Cursor did not reach owned target으로 클릭 전 거부됨. 그 이전 일부 시험에서도 우클릭 입력 자체가 전달되지 않았다. 메시지 주입 성공을 실제 마우스 전체 경로의 안정성으로 해석하지 않는다. 실제 사용자 보고의 좌클릭 오인 단일 원인은 미확정이며, 짝 없는 좌클릭 뗌 방어 및 교차 프로세스 메뉴 열기 경로 제거를 적용했다.
